v1 — “Manuscript & Brass” · cream-dominant, built for 45+ readability
The correction
Cream you can actually read

The old look leaned on a thin hairline serif and low-contrast copper-on-cream — elegant in a thumbnail, tiring for a 50-year-old on a phone. This keeps the warm parchment feel you wanted, but swaps in two clean, high-legibility sans faces, darker ink text, and contrast that clears WCAG AA everywhere. One deep-brown band is the only dark moment on the page.

✦

02 — Type
Two faces, both easy on older eyes

Bricolage Grotesque for headings — modern, warm, even-weight (no vanishing hairlines). IBM Plex Sans for everything you read — a humanist face with a tall x-height built for long reading. Base body size is 18px, not 16, so 45+ readers aren’t squinting. Both are free (Google Fonts).

04 — Rules
Contrast do & don’t

✓ Do

  • Body text in Ink #241C14 on cream — always.
  • Body at 18px minimum; never below 16px anywhere.
  • Links & small accents in Copper Ink #8A4A1C.
  • Buttons: brown or deep-copper fill with light text.

✕ Don’t

  • No gold text on cream — it fails contrast.
  • No light copper (#A25E2A) for small text or links.
  • No thin hairline serif for headings — ever.
  • Don’t stack cream text on cream (the old ticker bug).

05 — Developer handoff
Copy-paste for your dev

Drop the font link in <head> and the variables into your global CSS. Everything above is built from exactly these tokens.

<!-- fonts: add to <head> -->
<link rel="preconnect" href="https://fonts.googleapis.com">
<link href="https://fonts.googleapis.com/css2?family=Bricolage+Grotesque:opsz,wght@12..96,500;12..96,600;12..96,700;12..96,800&family=IBM+Plex+Sans:wght@400;500;600;700&display=swap" rel="stylesheet">

/* design tokens */
:root{
  --cream:#FBF5EA;  --parchment:#F4E9D6; --sand:#EBDDC4; --border:#E0CFB0;
  --ink:#241C14;    --cocoa:#574636;
  --copper:#A25E2A; --copper-ink:#8A4A1C; --brown-deep:#33251A; --gold:#C49A4A;
}
body{
  background:var(--cream); color:var(--ink);
  font-family:"IBM Plex Sans",system-ui,sans-serif;
  font-size:18px; line-height:1.6;
}
h1,h2,h3,h4{ font-family:"Bricolage Grotesque",sans-serif; color:var(--ink); line-height:1.08; }
a{ color:var(--copper-ink); }
.btn{ padding:14px 24px; border-radius:12px; font-weight:600; border:2px solid transparent;
      box-shadow:0 2px 5px rgba(51,37,26,.10); transition:transform .12s, box-shadow .15s; }
.btn:hover{ transform:translateY(-1px); box-shadow:0 6px 15px rgba(51,37,26,.17); }
.btn-primary{ background:var(--brown-deep); color:var(--cream); }        /* boldest action */
.btn-copper{  background:#8A4A1C; color:#fff; }                          /* strong action, warm */
.btn-tonal{   background:#FFFDF8; color:var(--copper-ink); border-color:var(--copper-ink); } /* secondary – NOT a hollow outline */

Font alternates if you ever want to swap: headings → Sora or Hanken Grotesk; body → Source Sans 3. All free, all high-legibility. Tell me if you'd like to see the site's real hero section fully mocked up in this system next.
